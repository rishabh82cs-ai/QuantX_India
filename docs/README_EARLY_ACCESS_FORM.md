# Greexora Early Access Registration Form Update

This update adds a public early-access registration page at:

`https://quantx-india.com/early-access.html`

It also updates website navigation so the **Early Access** button opens the registration form instead of scrolling to the footer.

## Form behavior

This is a static GitHub Pages compatible form. It does not require a server.

When a visitor submits the form, the browser prepares an email to:

`rishabh82.cs@gmail.com`

The visitor can review and send the email from their own mail app.

## Future backend options

For automatic storage, connect this page to one of the following:

- Google Forms
- Formspree
- Airtable
- HubSpot/CRM
- A custom backend/database

Do not collect broker API keys, passwords, access tokens, PAN/Aadhaar, bank details, or confidential account information through this form.
