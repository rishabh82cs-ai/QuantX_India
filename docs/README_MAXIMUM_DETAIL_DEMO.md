# Greexora Maximum Detail Product Demo

This package updates the public website with a detailed, interactive, simulated Greexora demo page and fixes duplicate Demo links in site navigation.

## What the demo includes

- Interactive control panel for market universe, instrument, expiry, interval, history days, chart mode, and scenario.
- Simulated internal professional charting with hollow candles, classic candles, line/bar mode, volume pane, support/resistance, entry, stop-loss, target, and overlay markers.
- Candlestick pattern and price-action intelligence preview.
- Option-chain analytics with simulated strikes, CE/PE LTP, OI, OI change, IV, Delta, Gamma, bid/ask, ATM row, PCR, Max Pain, and OI pressure.
- Futures analytics with contracts, basis, rollover, OI, OI change, volume, and spot-vs-futures explanation.
- Strategy advisor and strategy builder preview.
- One-click order ticket, bracket order fields, risk engine, paper trade button, tradebook preview, and live confirmation gate.
- AI trade journal, EOD review, backtesting/replay preview, equity curve, alerts, compliance controls, and the full 40-module map.

## Compliance design

The page uses simulated demo data only. It does not claim TradingView affiliation, does not use TradingView branding, does not connect to a broker, and does not place live orders. It presents charting as Greexora's internal professional charting system.
