# Greexora TradingView-Safe Compliance Checklist

Use this checklist before publishing the Greexora website or app screens.

## Public wording

- [ ] Do not claim "TradingView-powered" unless a formal agreement exists.
- [ ] Do not claim "official TradingView charts" unless a formal agreement exists.
- [ ] Do not claim "TradingView integrated" unless a formal agreement exists.
- [ ] Use "professional internal charting system" for Greexora charting.
- [ ] Use "broker-connected order workflow" rather than "automatic live trading".

## Charting libraries

- [ ] If using only Greexora's custom chart engine, do not use TradingView branding.
- [ ] If using Lightweight Charts, keep the Apache 2.0 license and required attribution/notice.
- [ ] If using Advanced Charts, obtain TradingView approval first.
- [ ] If using Trading Platform library, obtain TradingView approval first and verify broker/data/order backend integration.

## Market data

- [ ] Do not scrape TradingView chart data.
- [ ] Do not use TradingView personal subscription data commercially.
- [ ] Use approved broker APIs, exchange-authorised sources, licensed vendors, or legally permitted data sources.
- [ ] Record source, license/permission, rate limits, and permitted usage.

## Website claims

- [ ] No guaranteed-profit wording.
- [ ] No sure-shot, fixed income, 100% accuracy, risk-free, or automatic profit language.
- [ ] Include derivatives risk disclosure.
- [ ] State that all live orders require user confirmation.
- [ ] State that paper trading is the default safety mode.
- [ ] State that users remain responsible for all trading decisions.

## Required footer disclaimer

Greexora is an analytics, charting, strategy-planning, risk-management, paper-trading, journaling, backtesting, and broker-execution support platform. Greexora does not guarantee profits, does not eliminate trading risk, and does not provide risk-free trading outcomes. All trading decisions, live order confirmations, and risk responsibility remain with the user. Greexora is not affiliated with TradingView unless explicitly stated under a formal agreement.
