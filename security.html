Security posture

Credential handling and responsible market-data use

QuantX India is designed around local user-controlled credentials and authorised datafeed access.

Local credentials

Broker/API credentials are intended to be stored locally in the user's environment and not collected through this public website.

No public trading service

The website is informational. It does not offer public brokerage, investment advice, managed accounts or order routing.

Rate-limit awareness

Backend architecture includes caching and controlled refresh design to reduce unnecessary broker API calls.

Review and audit trail

Trade workflow modules are designed for structured journal output, review logs and safer user decision processes.
