Compliance and public positioning

Risk-first, license-aware, user-confirmed workflows.

This page defines the public compliance position for Greexora’s charting, data, broker integration, risk, AI, and execution-support features.

TradingView-safe charting position

Greexora should describe its charting as an internal professional charting system unless a formal TradingView agreement exists.

No implied affiliation

Greexora is not affiliated with TradingView unless explicitly stated under a formal agreement.

No unauthorised claims

Do not use phrases such as TradingView-powered, official TradingView charts, or TradingView integrated unless approval is obtained.

Approved library use only

Any open-source charting component must be used according to its license and attribution requirements.

Advanced libraries only after approval

TradingView Advanced Charts or Trading Platform libraries must only be used after formal approval and under permitted terms.

Market data and broker API policy

Greexora must use approved broker APIs, licensed market-data vendors, exchange-authorised sources, or other legally permitted data sources.

Permitted data path

Broker API, approved exchange feed, authorised vendor, or legally permitted historical/source data.

Not permitted

No scraped TradingView data, no personal TradingView subscription data, and no use of browser sessions as backend data sources.

Audit requirement

Maintain data-source records, API permissions, vendor licenses, and rate-limit notes.

Trading risk and execution safeguards

Greexora must remain a decision-support and execution-support platform, not a guaranteed-profit system.

Paper mode default

Paper trading should remain enabled by default before live execution is allowed.

Manual live confirmation

Every live order must require final user confirmation. No silent live execution.

No misleading claims

Avoid guaranteed, sure-shot, fixed profit, 100% accuracy, risk-free, or automatic profit claims.

Website footer disclosure: Greexora is an analytics, charting, strategy-planning, risk-management, paper-trading, journaling, backtesting, and broker-execution support platform. Greexora does not guarantee profits, does not eliminate trading risk, and does not provide risk-free trading outcomes. All trading decisions, live order confirmations, and risk responsibility remain with the user. Greexora is not affiliated with TradingView unless explicitly stated under a formal agreement.
