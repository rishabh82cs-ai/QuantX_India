Integration request summary

This page explains why QuantX India requested TradingView charting access and how the library is intended to be used.

Request purpose

QuantX India requests TradingView charting access to provide a professional-grade charting experience inside a private trading analytics terminal for Indian index and options markets.

Data source

The platform uses its own backend datafeed based on Dhan API market data. TradingView charts would consume QuantX backend endpoints rather than unauthorised scraped data.

Deployment model

The charting library is intended for use inside the QuantX India private desktop/web terminal. It is not intended as a public charting website or generic chart widget clone.
